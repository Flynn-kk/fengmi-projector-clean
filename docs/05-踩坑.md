# 05 · 踩坑合集

## 1. 装完必须启动一次 MainActivity

`adb install` 之后应用处于 **stopped** 状态：

- 开机广播收不到
- 它发起的 Activity 启动会被 AMS 直接拒（`Activity start request from 10123 stopped`）

```powershell
adb shell am start -n com.dsh.peppa.guard/.MainActivity
adb shell input keyevent KEYCODE_BACK
```

## 2. adb 发不了开机广播

```powershell
adb shell am broadcast -a android.intent.action.BOOT_COMPLETED -n com.dsh.peppa.guard/.BootReceiver
# SecurityException: not allowed to send broadcast android.intent.action.BOOT_COMPLETED from uid 2000
```

保护广播 shell 也发不了。想测开机逻辑只能真的重启。

## 3. adb 注入的 Home 键测不出按键过滤

`input keyevent 3` 不走无障碍的按键过滤，看起来像"没生效"。
必须按**真遥控器**测，见 [03](03-用无障碍吃掉Home键.md)。

## 4. 改 targetSdk 解决不了 stopped 拒绝

试过 28 → 27，没用。stopped 是安装状态的问题，不是 SDK 版本的问题。

## 5. javac 默认 GBK

这台 Windows 上 `javac` 默认按 GBK 读源码，中文注释会直接编译失败：

```
错误: 编码GBK的不可映射字符
```

所有编译命令都要加 `-encoding UTF-8`。

## 6. 反编译系统 jar 是白费劲

`/system/framework/services.jar`、`framework.jar` 都只有 **183 字节**（壳），
真代码在 odex/vdex 里。想靠反编译查日志来源行不通。

## 7. 开机时会闪一下小爱授权页

见过一次 `cn.formovie.fengos.assist/.XiaoaiOAuth.OAuthActivity`（小米账号/小爱授权）弹出，
之后自己消失。**跟守卫无关**，是 FENG OS 自己的行为。

## 8. 遥控器「应用」键只有奇异果桌面响应

`KEYCODE_ALL_APPS` 原本只有系统桌面处理。因为奇异果桌面**没被禁用**，
这个键现在仍然工作（会跳到奇异果桌面的应用列表）。如果以后禁用系统桌面，这个键就废了。
