# 01 · 机型与环境

| 项 | 值 | 怎么拿到的 |
|---|---|---|
| 型号 | `Xiaomi_Peppa_Series_Projector`，device `peppa` | `getprop ro.product.model` |
| 品牌 | Fengmi（峰米） | `ro.product.brand` |
| 系统 | Android 9 / SDK 28，Amlogic | `ro.build.version.release` |
| 固件 | `PPR1.180610.011.3.1.1.3775` | `ro.build.display.id` |
| 安全 | SELinux **enforcing**，**无 root** | `getenforce` / `id` |
| 屏幕 | 1920×1080，density 320 | `wm size` / `wm density` |
| ADB | `5555` 常开，首次连接要在投影仪上点「允许」 | — |

注意和创维那台的区别：**这台没有 root，SELinux 是 enforcing**，所以 `setprop persist.*` 这条路
（创维那台用的）走不通，只能用应用层手段。

## 自带的几层桌面

| 包名 | 是什么 | 位置 |
|---|---|---|
| `com.tvfengmi.launcher` | 奇异果 / GITV 桌面，v14.2.0.175155 | `/system/priv-app/GitvVideo` |
| `com.gala.video.app.epg.HomeActivity` | 它的首页 Activity | — |
| `com.android.tv.settings/.system.FallbackHome` | 兜底桌面，显示 FengOS 开机/自动对焦画面 | 系统 |
| `com.spocky.projengmenu` | Projectivy Launcher v4.63（替代桌面） | `/data/app` |

FENG OS 从 2025 年起把奇异果桌面强行顶成默认，取代了原来的自绘桌面。

## 改造前先存档

```powershell
adb shell pm list packages            > pre-packages.txt
adb shell pm list packages -d         > pre-disabled.txt
adb shell "cmd package query-activities -a android.intent.action.MAIN -c android.intent.category.HOME" > pre-home.txt
adb shell settings get secure enabled_accessibility_services > pre-a11y.txt
```

实测这台机器改造前只禁用了两个包：`com.ktcp.video`（奇异果 App）和 `com.shafa.market`（沙发管家）。
**奇异果桌面 `com.tvfengmi.launcher` 从头到尾没被禁用过。**
