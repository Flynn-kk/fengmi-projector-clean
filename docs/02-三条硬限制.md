# 02 · 三条硬限制（都实测过，别再试了）

## 1. 只允许系统应用当默认桌面

Projectivy、AS Launcher 都在清单里声明了 `HOME`，但系统根本不把它们当候选：

```powershell
$ adb shell cmd package set-home-activity com.spocky.projengmenu/.ui.home.MainActivity
Exception: IllegalArgumentException: ... cannot be home on user 0
```

`getHomeActivities()` 里只有系统那几个。**这条路直接封死**，别再试 `set-home-activity` 了。

## 2. 禁用奇异果桌面 = Home 键掉进 FallbackHome

试过最直觉的做法：`pm disable-user com.tvfengmi.launcher`。

结果按 Home 键会显示 FengOS 的「自动调焦中」画面（`com.android.tv.settings/.system.FallbackHome`），
再等 **4~6 秒**才被 Projectivy 抢回来。

比不禁用还难看，所以**已经恢复 enabled**。

## 3. AMS 在 HOME 启动的那几秒会掐掉别的启动请求

日志原文：

```
Activity start request from 10123 stopped
```

`com.tvfengmi.launcher` 正在 resume 的那几秒里，无论是 Projectivy 自己、还是第三方 App
去 `startActivity`，请求都会被拒，大约 5 秒后才放行。

**结论**：纯靠"抢"，开机和回桌面一定有 3~6 秒的奇异果闪屏；想彻底干净，必须从按键那一层截胡
（见 [03](03-用无障碍吃掉Home键.md)）。
